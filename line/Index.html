📖 Как играть

Цель: Соединить все точки в один путь, посетив цели по порядку.

  • 🔹 Начинайте с любой непосещённой точки (лучше с цели #1).
  • 🔹 Ходите на соседние клетки (включая диагонали).
  • 🔹 Золотые числа — цели, посещайте их строго по порядку.
  • 🔹 Тёмные точки — стены, их нельзя проходить.

Сложность:

  • 🟢 Лёгкая — 4×4, мало стен, 3 цели
  • 🟡 Средняя — 5×5, среднее число стен, 4 цели
  • 🔴 Сложная — 6×6, много стен, 5 целей, таймер 45с

Управление:

  • 🖱️ Клик / перетаскивание
  • Ctrl+Z Отмена
  • R Сброс
  • N Новая карта
  • S Показать решение
