📘 Crypto Double-Cross + Telegram

Профессиональный мониторинг резких движений цены с двойной фильтрацией и отправкой алертов в Telegram.

🎯 Принцип работы

Алгоритм отслеживает цену выбранных монет в реальном времени через WebSocket Binance. При изменении цены вычисляется процент изменения относительно базовой цены (цены на момент запуска трекера).

Механизм "Double Cross": Вы задаёте список порогов для роста и падения. Если монета впервые пересекает любой из порогов, это фиксируется как одно пересечение. За заданный интервал времени необходимо набрать заданное количество пересечений — тогда генерируется АЛЕРТ.

Каждый порог срабатывает только один раз за "сессию".

📈 Настройка порогов через интервал

В блоке «Пороги» вы можете автоматически сгенерировать списки порогов роста и падения, указав:

  • от — минимальное значение (включительно)
  • до — максимальное значение (включительно)
  • шаг — приращение между значениями

Например, диапазон 3–15 с шагом 2 даст пороги: 3, 5, 7, 9, 11, 13, 15. Значения округляются до одного знака после запятой.

Также вы можете добавлять отдельные пороги вручную или удалять их крестиком. Кнопка «Классический» загружает предустановленный набор.

🤖 Настройка Telegram

  • Найдите в Telegram @BotFather, создайте нового бота командой /newbot.
  • Получите Bot Token (пример: 123456:ABC-DEF1234ghIkl).
  • Напишите своему боту любое сообщение, затем перейдите по ссылке https://api.telegram.org/bot<ваш_токен>/getUpdates — найдите там chat id (число).
  • Вставьте токен и chat id в соответствующие поля. Кнопка "Тест" отправит проверочное сообщение.

При запуске трекера и при каждом срабатывании двойного алерта будет отправляться сообщение в Telegram (если поля заполнены).

💾 Автосохранение и экспорт

Все настройки автоматически сохраняются в браузере (localStorage) при каждом изменении. При повторном открытии страницы настройки восстанавливаются.

Вы также можете экспортировать настройки в JSON-файл (кнопка «Экспорт») и импортировать их обратно (кнопка «Импорт»), чтобы перенести конфигурацию между устройствами или сохранить резервную копию.

⚙️ Остальные настройки

  • Интервал (сек): окно времени для набора пересечений.
  • Пересечений: сколько порогов должно быть пересечено за интервал.
  • Кулдаун (сек): после срабатывания алерта монета игнорируется на это время.
  • Звук и Голос: опциональные оповещения в браузере.

📊 Интерфейс

Таблица текущих цен показывает последнюю цену, изменение, количество пересечений и статус. Монеты в алерте — список монет, набравших нужное количество пересечений (можно вручную протестировать оповещение). Журнал событий — хронология всех пересечений и алертов.
