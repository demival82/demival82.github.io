Профессиональный мониторинг резких движений цены на криптовалютных парах USDT с двойной фильтрацией. Инструмент создан для трейдеров, которым важно не пропустить моменты высокой волатильности и повторные пробои уровней за короткий промежуток времени.

🎯 Принцип работы (детально)

Алгоритм отслеживает цену выбранных монет в реальном времени через WebSocket Binance. Каждые 1.5 секунды обновляется таблица цен. При изменении цены система вычисляет процентное изменение относительно базовой цены (цены на момент запуска трекера или последнего обновления).

Механизм "Double Cross": Вы задаете список порогов для роста (например, +5%, +10%) и падения (-4%, -8%). Если монета впервые пересекает любой из порогов (например, рост на 5.2%), это фиксируется как одно пересечение. За заданный интервал времени (по умолчанию 30 секунд) необходимо набрать заданное количество пересечений (по умолчанию 2). Как только условие выполнено — генерируется АЛЕРТ.

Важно: Каждый порог срабатывает только один раз за "сессию" (до сброса счетчика). Например, если цена выросла на 5%, потом упала, и снова выросла на 5% — второй рост по тому же порогу не засчитается. Но если цена вырастет на 5%, а затем на 10% — это два разных порога = два пересечения.

📈 Управление порогами и пресетами

Пресеты с шагом: в блоке "Быстрый выбор пресетов" вы можете сгенерировать списки порогов для роста и падения в диапазоне от 3% до 40% с шагом 0.2%, 0.5%, 1% или 2%. Это удобно для создания сетки уровней (например, 3%,4%,5%...40% при шаге 1%).

Ручное добавление: в разделе "Пороги" можно добавлять любые значения вручную (с шагом 0.2%). Удалить ненужный порог — кликнуть на крестик рядом с ним.

Пример настройки под волатильную монету: для скальпинга на BTC можно поставить пороги роста +0.8%, +1.2%, +1.6% и падения аналогично, интервал 15 секунд, 2 пересечения. Для альткоинов с высокой волатильностью — пороги +4%, +7%, +10%.

⏰ Авто-напоминание (новая функция)

Система будет автоматически оповещать вас через заданный интервал (например, каждые 20 минут) текстовым сообщением, звуком и голосом. Это полезно, чтобы не забывать следить за экраном или проверять, активен ли трекер. Сообщение можно настроить любое, например: "Проверь позиции, мониторинг активен".

🤖 Настройка Telegram бота

1. Найдите в Telegram @BotFather, создайте нового бота командой /newbot.
2. Получите Bot Token (пример: 123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11).
3. Напишите своему боту любое сообщение, затем перейдите по ссылке https://api.telegram.org/bot<ваш_токен>/getUpdates — найдите там chat id (число).
4. Вставьте токен и chat id в соответствующие поля. Кнопка "Тест" отправит проверочное сообщение.

🎛️ Условие срабатывания (настройки)

  • Интервал (сек): окно времени, в течение которого нужно набрать пересечения. По умолчанию 30 секунд.
  • Пересечений: сколько порогов должно быть пересечено за интервал. По умолчанию 2. Если поставить 3 — потребуется 3 разных порога за 30 секунд.
  • Таймаут (сек): после срабатывания алерта монета игнорируется на это время, чтобы избежать повторных оповещений.
  • Звук алерта: можно выбрать стандартный звонок или колокол.
  • Голос: при включении будет произноситься название монеты и событие на русском.

⏳ Задержка API (новая настройка)

При загрузке страницы и при нажатии кнопки «Обновить монеты» запрос к Binance API (список всех торговых пар и 24-часовые объёмы) выполняется не мгновенно, а с заданной задержкой (по умолчанию 10 секунд). Это может быть полезно, чтобы избежать лишних запросов при частом обновлении или для синхронизации с другими действиями. Задержку можно настроить от 0 до 60 секунд.

📊 Интерфейс и мониторинг

Таблица текущих цен: показывает последнюю цену, процент изменения от базовой, количество набранных пересечений и статус (активен/кулдаун). Пересечений: 1/2 — значит одно пересечение из двух необходимых.

Монеты в алерте: здесь отображаются монеты, которые уже набрали нужное количество пересечений и готовы к оповещению (или только что оповещены). Кнопка "ALERT" позволяет вручную протестировать оповещение для этой монеты.

Журнал событий: хронология всех пересечений порогов, алертов, напоминаний и системных сообщений. Цветом выделяются двойные алерты.

💾 Сохранение и загрузка

Все настройки (списки монет, пороги, параметры интервалов, Telegram, напоминания, задержка API) сохраняются в браузере локально. Кнопка «Сохранить все параметры» — записать текущую конфигурацию. «Загрузить все параметры» — восстановить последнюю сохраненную. После загрузки параметров, если трекер активен, он перезапустится автоматически.

❓ Частые вопросы

  • Почему цена изменилась, а пересечение не засчиталось? Возможно, этот порог уже был пересечен ранее (до сброса счетчика) или вы не обновили базовую цену (трекер сбрасывает счетчики каждые 30 секунд автоматически).
  • Как часто обновляются цены? WebSocket обновления приходят мгновенно (каждые 1-2 секунды). UI обновляется каждые 1.5 секунды.
  • Можно ли отслеживать не только USDT пары? В текущей версии — только пары с USDT, так как API Binance берет именно их. При желании можно модифицировать скрипт.
  • Работает ли звук в фоне? Да, если браузер разрешает автоматическое воспроизведение. Рекомендуется один раз кликнуть по странице после загрузки.
